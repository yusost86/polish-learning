# Pol ↔ Укр — вивчення польських слів

PWA для вивчення польсько-українського словника з інтервальним повторенням
(алгоритм FSRS через `ts-fsrs`), офлайн-збереженням у IndexedDB (Dexie) та
UI, оптимізованим під iPhone 14 / 16 Pro Max (safe-area, великі кнопки,
темна кольорова схема).

## Що вміє застосунок

- **📋 Вставити JSON фрагмент** — додати свій набір слів у форматі
  `[{ "pl": "...", "uk": "...", "topic": "..." }]`. Слова групуються за
  полем `topic`, а якщо воно не вказане — за назвою набору.
- **📚 Теми** — вивчення нових слів або повторення тих, що вже "дозріли"
  за розкладом FSRS, окремо по кожній темі.
- **🔴 Повторити всі** — швидкий доступ до всіх прострочених повторень одразу.
- **🎴 Вправи з наростаючою складністю** — залежно від того, наскільки добре
  слово вже засвоєне (стабільність у FSRS), обирається один із трьох рівнів:
  1. **Легко** — вибір правильного перекладу з 4 варіантів.
  2. **Середньо** — слово показане з декількома прихованими буквами
     (спочатку 1 буква, далі 2-3), потрібно вписати повне слово.
  3. **Складно** — переклад потрібно вписати повністю самостійно, без
     жодних підказок.
  Система сама підвищує складність вправи для слова в міру того, як
  користувач відповідає правильно (і знижує, якщо є помилки — за рахунок
  того, що FSRS відповідно коригує стабільність).
- **📊 Статистика** — загальний прогрес, точність відповідей, streak-и,
  розподіл слів за рівнями.
- **📖 Всі слова** — пошук і сортування повного словника, деталі по кожному
  слову з історією повторень.
- Працює офлайн як PWA (service worker кешує застосунок після першого
  завантаження), дані зберігаються локально в IndexedDB.

## Запуск локально

```bash
npm install
npm run dev
```

Відкрийте посилання, яке виведе Vite (https, бо `server.https: true` у
`vite.config.ts` — на iPhone Safari потребує коректного сертифіката для
Service Worker; для локальної розробки можна прибрати `https: true`,
якщо сертифікат незручний).

## Збірка та деплой на GitHub Pages

```bash
npm run build     # tsc -b && vite build -> ./dist
npm run deploy     # публікує ./dist у гілку gh-pages
```

Базовий шлях застосунку — `/polish-learning/` (див. `base` у
`vite.config.ts`, `start_url`/`scope` у `public/manifest.json`). Якщо
розгортаєте під іншою назвою репозиторію/доменом — поміняйте всі три місця
на свій шлях.

## Встановлення на iPhone 14/16 Pro Max

1. Відкрийте опубліковану адресу в Safari.
2. Поділитися → «На екран Домівки».
3. Застосунок відкриється на весь екран без адресного рядка, з підтримкою
   вирізу/Dynamic Island (враховано через `env(safe-area-inset-*)`).

## Структура проєкту

```
src/
  domain/types.ts        доменні типи (Topic, Word, StudentWord, ...)
  db/db.ts                Dexie (IndexedDB) схема
  fsrs/                   планувальник, створення карток, обробка відповіді
  learning/               підбір слів для сесії, імпорт JSON, статистика
  hooks/                  useAppData (глобальний стан), useLearningSession
  screens/                MenuScreen, GameScreen, StatisticsScreen,
                          WordsListScreen, WordDetailScreen
```

## Відомі обмеження / можливі наступні кроки

- Тип вправи `CONTEXT` (переклад у контексті речення) закладений у моделі
  даних, але UI для нього ще не реалізований.
- `studentId` захардкоджений (`LOCAL_STUDENT_ID`), бо застосунок
  однокористувацький і без авторизації.
